{% trans "Basics" %}

{% trans "Every address starts with" %} {{ base_url }}/. {% blocktrans trimmed with url=openapi_url %}The same reference is available as an OpenAPI 3.1 document, for code generators and API tools.{% endblocktrans %}

  • {% blocktrans trimmed %}Answers are JSON (UTF-8). A list is an object {"data": [...], "next": "…"}; one object is returned as it is.{% endblocktrans %}
  • {% blocktrans trimmed %}Every object has its id, its address on the site (url) and, when it has one, its address in the API (api_url).{% endblocktrans %}
  • {% blocktrans trimmed %}Dates are ISO 8601 with the site's UTC offset, e.g. 2026-03-01T09:30:00+01:00.{% endblocktrans %}
  • {% blocktrans trimmed %}Posts come with their rendered HTML (html, as shown on the site) and their Markdown source (markdown).{% endblocktrans %}
  • {% blocktrans trimmed %}You see what the site shows you: deleted posts and posts waiting for a moderator are left out, except your own when you send your token.{% endblocktrans %}
curl "{{ example_question }}"

{% trans "Authentication" %}

{% blocktrans trimmed %}Reading needs no token. To post, vote or follow questions, and to see your own posts that wait for review, send a personal access token in the Authorization header:{% endblocktrans %}

curl -H "Authorization: Bearer $OSQA_TOKEN" "{{ base_url }}/me"
  • {% if tokens_url %}{% blocktrans trimmed with url=tokens_url %}Create tokens on your API tokens page.{% endblocktrans %}{% else %}{% trans "Sign in, then create tokens in your settings, under API tokens." %}{% endif %} {% trans "A token is shown once: copy it then. Only a fingerprint of it is stored." %}
  • {% blocktrans trimmed %}A token has the read scope, or read and write. It acts as you: the same reputation rules, posting limits, email confirmation and review of first posts apply as on the site.{% endblocktrans %}{% if not writes_enabled %} {% trans "Posting through the API is turned off on this site at the moment." %}{% endif %}
  • {% trans "Tokens expire after the time you choose, and you can revoke one at any time." %}
  • {% blocktrans trimmed %}The API never uses the sign-in cookie of the site: without a token you are an anonymous visitor, and nothing can be changed.{% endblocktrans %}

{% trans "Rate limits" %}

  • {% if limit_anonymous %}{% blocktrans trimmed with n=limit_anonymous %}Without a token: {{ n }} requests per minute per IP address.{% endblocktrans %}{% else %}{% trans "Without a token: no limit." %}{% endif %}
  • {% if limit_token %}{% blocktrans trimmed with n=limit_token %}With a token: {{ n }} requests per minute per token.{% endblocktrans %}{% else %}{% trans "With a token: no limit." %}{% endif %} {% if limit_writes %}{% blocktrans trimmed with n=limit_writes %}Of those, at most {{ n }} changes (posts, votes, accepts, follows).{% endblocktrans %}{% endif %}

{% blocktrans trimmed %}Each answer tells where you stand: X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset (seconds until the minute starts again). Over the limit, the answer is 429 with Retry-After (seconds). The site's hourly limits on questions, answers and comments also apply (429, posting-limit).{% endblocktrans %}

{% trans "Pages and caching" %}

  • {% blocktrans trimmed %}Lists take limit (1 to 100). next is the address of the next page (also in a Link: <…>; rel="next" header), or null on the last page. Follow it as it is: its cursor stays valid when new posts arrive.{% endblocktrans %}
  • {% blocktrans trimmed %}Single objects carry an ETag. Send it back in If-None-Match and you get 304 Not Modified when nothing changed.{% endblocktrans %}
  • {% if cors_origins %}{% blocktrans trimmed with origins=cors_origins|join:" " %}Web pages on other sites can read the API with JavaScript (CORS, GET only, without cookies) from: {{ origins }}.{% endblocktrans %}{% else %}{% trans "Web pages on other sites can't read the API with JavaScript (CORS is off)." %}{% endif %}
